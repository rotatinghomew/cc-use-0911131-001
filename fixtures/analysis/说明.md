# 经营分析样例

assignments 以 household_id 标识随机化家庭，arm 为登记分组。identities 中 link_id 的 revision 表示设备与家庭关系修订，revoked 表示撤回。events 区分 exposure、order、refund，退款使用 order_id 关联原交易；amount 单位为元。occurred_at 是发生时间，known_at 是资料可用时间，as_of 是观察资料截止点。

日期采用 ISO 8601；样例完全由固定种子生成，不含真实个人、机构或设备资料。字段缺省与数值零的含义不同。原有 fixtures/demo.json 仍用于既有业务流程。
